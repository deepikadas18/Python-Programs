## 💱 Currency Converter

An interactive GUI-based Currency Converter developed using **Python Tkinter**.

### Features

- Convert between INR, USD, EUR, and GBP
- Interactive graphical user interface
- Dropdown menus for currency selection
- Convert, Clear, Swap, and Exit buttons
- Error handling for invalid inputs
- Uses predefined exchange rates

### Technologies Used

- Python 3
- Tkinter (GUI)
